## ✦ Overview

**Velora** is a luxury perfume brand website designed to communicate the
identity, atmosphere and craftsmanship of a premium fragrance brand.

The website focuses on:

- Luxury visual presentation
- Editorial-style layouts
- Minimal and refined UI
- High-quality imagery
- Responsive design
- Smooth and purposeful animations
- Accessible navigation
- Clean and maintainable React architecture

Velora is designed as a **brand experience website**, not as a traditional
e-commerce platform.

---

## ✦ Design Direction

The visual direction of Velora follows a combination of:

- Luxury
- Minimalism
- Editorial design
- Modern aesthetics
- Cinematic imagery
- Generous whitespace
- Refined typography
- Subtle interactions

The interface intentionally avoids excessive:

- Cards
- Shadows
- Gradients
- Decorative UI
- Unnecessary animations
- E-commerce elements

The goal is to make the **brand and fragrance imagery the primary focus**.

## ✦ Responsive Breakpoints

Velora uses custom responsive breakpoints instead of the default Tailwind
breakpoints.

| Breakpoint | Width |
|------------|-------|
| `mobile` | `360px` |
| `mobile-lg` | `480px` |
| `tablet` | `768px` |
| `laptop` | `1024px` |
| `desktop` | `1280px` |
| `wide` | `1536px` |
